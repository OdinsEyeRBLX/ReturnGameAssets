# Asset Scanner UI
This tool is made to purely identify and list `sound`, `mesh` and `animation` IDs found throughout the game.
**Before using, please make a `RemoteEvent` called `AssetScannerUpdate` within the `ReplicatedStorage`.**

- [Use this lua code](https://github.com/OdinsEyeRBLX/ReturnGameAssets/blob/main/ScanWithinScripts.lua) in the run terminal of the studio to scan within scripts of the game file.
- For the GameUI version which scans through all objects of the game, use the `LocalScript.lua` and `ServerScript.lua` files.

You can then identify the ownership of the asset using our [Asset Checker](https://github.com/OdinsEyeRBLX/RobloxSafetyUtilities/blob/main/JavaScript/asset_checker.js) JavaScript code or the [S.C.O.U.T. Utility](https://scout-utility.onrender.com/) website.
